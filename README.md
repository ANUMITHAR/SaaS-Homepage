
# Modern SaaS Homepage

A clean and responsive **Modern SaaS Homepage** built using **HTML and CSS**.  
This project is suitable for beginners who want to practice frontend layout, UI design, and basic web structure.

---

## Features

- Modern SaaS-style UI design
- Clean and structured HTML
- Separate CSS for styling
- Hero section with call-to-action
- Feature cards section
- Simple navigation bar
- Footer section

---

## Technologies Used

- HTML5
- CSS3

---

##  Project Structure

```

Modern-SaaS-Homepage/
│
├── index.html
├── style.css
└── README.md

```

---

##  How to Run the Project

1. Download or clone this repository
2. Open the folder in **VS Code**
3. Open `index.html`
4. Right-click → **Open with Live Server**  
   (or double-click `index.html` to open in browser)
